# Code of conduct

This project follows the **Contributor Covenant, version 2.1**. Its full text is published by the Contributor
Covenant project under that name and version.

In short:

- Be respectful and patient. Assume good intent, and say plainly what you mean.
- Criticise code and ideas, not people.
- No harassment, insults, sexualised language or attention, or publishing of anyone's private information.

This applies in the project's issues, pull requests, discussions and any other space the project uses.

To report behaviour that breaks this code, use the reporting tools of the platform that hosts the repository. The
project's maintainers read reports there and may remove comments, close threads or block accounts. Reports are
handled on a best-effort basis and kept as private as the platform allows.
